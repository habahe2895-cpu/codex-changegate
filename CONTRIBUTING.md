# Contributing

Thanks for helping improve ChangeGate.

1. Open an issue outlining the bug or proposed feature.
2. Fork and create a feature branch with a focused change.
3. Run `python -m unittest discover -s tests -v`.
4. Submit a pull request explaining motivation, changes and how to test.
5. Maintainers will review the code; protected paths need the configured votes.

Please do not submit credentials, account data, or proprietary code.

Suggested starter work: document cross-platform setup, add end-to-end API
mock tests, or improve reporting output.
